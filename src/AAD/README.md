# Application Architecture and Design (AAD) Labs

Welcome to the Application Architecture and Design (AAD) Labs! This series of labs is designed to introduce you to fundamental concepts and practical skills in building, containerizing, and deploying applications using Flask, Docker, Docker Compose, and Kubernetes.

Each lab is self-contained within its directory and includes an `instructions.md` file to guide you through the exercises.

## Labs Overview

Here's a list of the labs available:

*   **[Lab 1: Flask Hello World](simple_labs/1_flask_hello_world/instructions.md)**
    *   Learn to create and run your very first Flask web application.
*   **[Lab 2: Flask URL Parameters](simple_labs/2_flask_url_params/instructions.md)**
    *   Understand how to handle URL parameters and process incoming data in Flask applications.
*   **[Lab 3: Docker Flask App](simple_labs/3_docker_flask_app/instructions.md)**
    *   Containerize a simple Flask application using Docker.
*   **[Lab 4: Docker Publish Image](simple_labs/4_docker_publish_image/instructions.md)**
    *   Learn to build a Docker image and publish it to a public registry like Docker Hub.
*   **[Lab 5: Docker Compose Intro](simple_labs/5_docker_compose_intro/instructions.md)**
    *   Use Docker Compose to define and run a simple multi-container application.
*   **[Lab 6: Docker Compose Volumes](simple_labs/6_docker_compose_volumes/instructions.md)**
    *   Explore how to persist data generated by Docker containers using volumes with Docker Compose.
*   **[Lab 7: Kubernetes Basics](simple_labs/7_kubernetes_basics/instructions.md)**
    *   Deploy a basic Nginx web server on a Kubernetes cluster and expose it using a NodePort Service.
*   **[Lab 8: Kubernetes Advanced](simple_labs/8_kubernetes_advanced/instructions.md)**
    *   Dive into more advanced Kubernetes concepts, including different Service types (ClusterIP, LoadBalancer) and persistent storage using Persistent Volumes and Claims.

---

**Getting Started:**

Navigate into each lab's directory and follow the `instructions.md` file to complete the exercises.
